# OpenClaw Knowledge Wiki Automation

## Purpose

This directory contains future automation policy files for controlled GitHub PR workflows around OpenClaw Knowledge Wiki.

## Current status

The real runner does not exist yet.

Expected future runner path:

```text
projects/openclaw-knowledge-wiki/automation/github_pr_workflow_runner.py
```

Current intended policy path:

```text
projects/openclaw-knowledge-wiki/automation/policies/github_pr_workflow.policy.yml
```

## Important

Having policy files here does not activate automation.

No workflow runs automatically because of this directory.

## Runtime state

Runtime state must not be versioned.

Ignored paths include:

```text
automation/run_state/
automation/approvals/
```

Snapshots, if created by a future runner, must live under:

```text
automation/run_state/<run_id>/snapshots/
```

They are covered by ignoring:

```text
automation/run_state/
```

Runtime state may contain temporary state, snapshots, approvals, rollback metadata, or logs generated by future controlled runs.

## Safety boundaries

The initial target change class is:

```text
DOCS_LOW_RISK
```

Allowed scope is limited to:

```text
projects/openclaw-knowledge-wiki/wiki/concepts/**
projects/openclaw-knowledge-wiki/wiki/index.md
projects/openclaw-knowledge-wiki/wiki/log.md
```

Forbidden by default:

```text
projects/openclaw-knowledge-wiki/raw/**
.env
**/.env
**/*token*
**/*secret*
**/*credential*
**/*.pem
**/*.key
logs/**
systemd/**
rag_store/**
context_repo/personal/**
.git/**
```

## v0.1 limitation

Runner v0.1, when implemented, should only support:

```text
plan
check
```

It must not implement:

```text
copy
commit
push
pr
merge
```

There is no merge command in v0.1.

Auto-merge is disabled and reserved only as a future design topic.

## Activation rule

Do not treat this directory, policy, or README as authorization to run automation.

Any future runner implementation requires explicit Albert authorization, review, and validation.
