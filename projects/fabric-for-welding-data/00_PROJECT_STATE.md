# 00_PROJECT_STATE

## Proyecto
fabric-for-welding-data

## Objetivo
Entender Microsoft Fabric a nivel experto para aplicarlo a datos industriales de soldadura por puntos en automoción.

## Enfoque
No se trata de recopilar noticias de Fabric sin criterio.

Cada fuente debe responder a esta pregunta:

¿Esto mejora el sistema de datos de soldadura?

## Outputs esperados
- Decisiones de arquitectura Fabric aplicables a soldadura por puntos.
- Mapas entre componentes Fabric y problemas reales de planta.
- Casos de uso sobre RD, corriente, defectos, robots, alertas y dashboards.
- Resúmenes técnicos accionables.
- Identificación de mejoras prácticas para entornos industriales.

## Primer foco recomendado
Real-Time Intelligence aplicado a soldadura por puntos.

Motivo:
Conecta con alertas, RD alta, robots, defectos, dashboard y reacción temprana.
