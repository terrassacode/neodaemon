# Visualitzador Cívic CAT

Aplicació web experimental per transformar informació pública extensa en informes visuals clars en català.

## Estat

Proposta inicial / MVP aïllat.

## Objectiu

Permetre introduir URL, text llarg o CSV relacionat amb informació pública, contractació, notícies institucionals o anàlisi cívica, i generar una peça visual clara, prudent i exportable a PDF.

## Principis

- No afirmar corrupció sense proves.
- Separar fets, indicis, interpretacions i preguntes obertes.
- No inventar dades.
- No fer hype.
- Treballar sempre en català normatiu.

## Aïllament

Aquest projecte viu només dins de:
