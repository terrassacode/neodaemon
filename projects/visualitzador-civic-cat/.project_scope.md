# Project Scope — visualitzador-civic-cat

Estado: activo
Responsable operativo: Neodaemon MAIN
Autorizado por: Albert

## Propósito

Crear un MVP web aislado llamado Visualitzador Cívic CAT para convertir información pública extensa en informes visuales claros en catalán.

## Alcance

Este proyecto puede:

- crear una app frontend local;
- usar datos públicos, sintéticos o pegados manualmente;
- generar informes visuales;
- exportar mediante impresión del navegador;
- trabajar dentro de su propia carpeta.

## Fuera de alcance

Este proyecto no puede:

- modificar core OpenClaw;
- modificar scripts globales;
- modificar dashboard-v2;
- modificar logs;
- modificar RAG;
- modificar Gmail;
- modificar Telegram;
- modificar systemd;
- modificar gateway;
- ejecutar ru_event.sh;
- ejecutar ru_interaction.sh;
- escribir fuera de su carpeta;
- conectar APIs externas sin autorización explícita.
